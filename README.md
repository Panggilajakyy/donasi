# Website Donasi Online

Aplikasi web portal donasi online berbasis PHP native dan MySQL.

## Fitur Utama
- **Program Donasi**: Donasi Darurat, Kesehatan, Pemberdayaan, Pendidikan, dan Santunan Anak Yatim.
- **Pembayaran Donasi**: Integrasi form donasi & konfirmasi pembayaran.
- **Panel Admin**: Manajemen data donasi, pelaporan, dan notifikasi donasi masuk.
- **Notifikasi Live**: Fitur notifikasi donasi real-time.

## Persyaratan Sistem
- Web Server: Apache (Laragon / XAMPP)
- PHP versi 7.4 atau lebih baru
- MySQL Database (`donasi`)

## Instalasi
1. Pindahkan folder project ke direktori web server (`C:/laragon/www/donasi` atau `htdocs/donasi`).
2. Buat database baru bernama `donasi` di phpMyAdmin / MySQL.
3. Sesuaikan konfigurasi database di file `koneksi.php` jika diperlukan.
4. Buka browser dan akses `http://localhost/donasi/`.
